# Datheon Python Programming Internship

## About This Repository

This repository contains Python programming projects completed as part of the **Datheon Python Programming Internship**.

The projects demonstrate fundamental Python programming concepts, problem-solving skills, file handling, and practical application development.

## Completed Tasks

### Task 1: Hangman Game

A Python-based word guessing game where players guess letters to identify a hidden word.

**Features:**
- Random word selection
- Letter-by-letter guessing
- Limited incorrect attempts
- Hangman visual representation
- Win and lose conditions
- Input validation

**Project Folder:** `Task_1_Hangman`

### Task 2: Stock Portfolio Performance Tracker

A Python application that calculates and tracks stock portfolio performance using sample stock price data.

**Features:**
- Multiple stock entries
- Stock ticker lookup using an S&P 500 dataset
- Automatic sample price lookup from CSV
- Investment and market value calculations
- Profit/loss and percentage calculations
- Portfolio summary exported to CSV

**Project Folder:** `Task_2_Stock_portfolio`

## How to Run

1. Download or clone this repository.
2. Install Python 3 if it is not already installed.
3. Open the required task folder in Command Prompt.
4. Run the corresponding Python script.

For Task 1:

`py hangman.py`

For Task 2:

`py portfolio.py`

Detailed instructions are available in each task folder's README.
