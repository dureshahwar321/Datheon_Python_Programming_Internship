
# Hangman Game in Python

## Project Description
This is a terminal-based Hangman Game developed
as part of my Datheon Python Programming Internship.

## Features
- Random word selection
- Six wrong attempts allowed
- ASCII Hangman drawings
- Correct and wrong guess messages
- Repeated guess detection
- Input validation
- Winning and losing conditions

## Technologies Used
- Python 3
- VS Code
- Random module

## How to Run
1. Install Python 3.
2. Open the project folder.
3. Run: python hangman.py
4. Guess the hidden word one letter at a time.
